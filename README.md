## 📌 소개 (About)

`my-link-hy`는 개인 프로필, 소셜 미디어(SNS) 링크, 블로그 및 포트폴리오 카드를 한곳에 모아 모바일과 데스크톱 화면에 깔끔하고 직관적인 카드 형태로 제공하는 모던 프로필 링크 모음 웹 애플리케이션입니다.

- **작성자 / 소유자**: qkrskfla0904
- **개발 언어 및 프레임워크**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4

## ✨ 주요 기능 (Key Features)

- **👤 프로필 헤더**: 사용자 아바타, 이름, 한 줄 소개(Bio) 표시
- **🔗 카테고리별 링크 카드**: 포트폴리오, SNS, 블로그, 연락처 등 카테고리 태그 및 설명 제공
- **📱 반응형 디자인**: 모바일 호환 중심의 직관적 UI/UX
- **🎨 다크 모드 지원**: 최신 CSS 기반 차분하고 세련된 스타일링

## 🚀 실행 방법 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속 후 확인 가능합니다.

### 3. 빌드 및 시작
```bash
npm run build
npm run start
```
