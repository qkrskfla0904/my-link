# [와이어프레임] 마이링크 (MyLink) 메인 화면 (방문자 뷰)

본 문서는 **방문자(팬, 채용담당자 등)가 크리에이터의 마이링크(`/@username` 또는 `/`)에 접속했을 때 보게 되는 메인 화면의 레이아웃과 UI 컴포넌트 구조**를 정의합니다.

---

## 1. 반응형 레이아웃 구조 (Layout Overview)

마이링크는 **모바일 퍼스트(Mobile-First)**로 설계되었으며, 화면 너비에 따라 2가지 형태로 최적화되어 표시됩니다:
- **모바일 뷰 (<= 768px)**: 1열 수직 스택형 (스마트폰 인앱 브라우저 최적화)
- **데스크톱 뷰 (> 768px)**: 2열 모듈형 그리드 (좌측 2/3 메인 콘텐츠 + 우측 1/3 인터랙션/위젯 레일)

---

## 3. 핵심 컴포넌트별 명세

| 영역 | 컴포넌트명 | 역할 및 구성 요소 |
| :--- | :--- | :--- |
| **Header** | `Header.tsx` | 브랜드 로고, 라이브 인디케이터, 전체 페이지 공유 버튼 |
| **Profile** | `ProfileHeader.tsx` | 프로필 아바타, 닉네임, Bio 설명, 태그 배지, 커피챗/구직 상태 표시등 |
| **Filter** | `CategoryFilter.tsx` | 카테고리 탭 (전체 / 포트폴리오 / 블로그 / SNS / 연락처) 즉시 필터링 |
| **Links** | `LinkCard.tsx` | 아이콘(GitHub, Blog, Mail 등), 제목, 서브텍스트, 클릭수, 인기 배지, 새 창 열림 링크 |
| **Theme** | `ThemePicker.tsx` | 5가지 테마 액센트(Violet, Emerald, Sky, Rose, Amber) 실시간 스위칭 |
| **Widget** | `page.tsx` (우측) | 서비스 소개 카드, Player's Poll(인터랙티브 투표 위젯), 인증 뱃지 |
| **Modal** | `ShareModal.tsx` | URL 클립보드 복사, QR 코드 표시, 소셜 미디어 공유 |
